# JET Games

Portfolio de juegos mobile-first publicados bajo **JETCompany OÜ** (Estonia).
Reimaginaciones modernas y monetizables de clásicos pre-2000.

## Apps en el portfolio

| Marca | Inspiración | Estado | Carpeta |
|---|---|---|---|
| **JETBALL** (`jetball/`) | JezzBall (1992) | en producción | [jetball/](./jetball) |
| **JETDrift** (`jetdrift/`) | Hover! (1995) | v0.4 — Dunes theme en construcción | [jetdrift/](./jetdrift) |
| **JETFlow** (`jetflow/`) | Pipe Mania (1989) | v0.1 prototipo playable | [jetflow/](./jetflow) |
| **JETSlalom** (`jetslalom/`) | SkiFree (1991) | v0.1 prototipo playable | [jetslalom/](./jetslalom) |

## Stack técnico común

- HTML5 + WebGL/Canvas2D
- Capacitor wrap → Android (Play Store) / iOS (App Store)
- AdMob + Google Play Billing para monetización
- Firebase Analytics + Crashlytics
- Hostinger hosting web + dominios per-game
