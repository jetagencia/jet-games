# JETDrift

Reimaginación 2026 de **Hover!** (Microsoft, 1995). Mobile-first, multi-modo, multi-POV, multi-theme.

**Estado actual**: pre-v0.4. Las versiones v0.1 / v0.2 / v0.3 están descartadas — se construye nuevo desde el diseño consensuado.

**Design doc**: ver [`../docs/DESIGN-1.0.md`](../docs/DESIGN-1.0.md) — visión, themes (Dunes/Spire), modos (Carrera/Paseo/Cacería/etc.), POVs, controles, roadmap.

**Próximo milestone (v0.4)**: theme Dunes (Alto's Odyssey-inspired warm pastel low-poly) + modo Carrera + POV tercera persona. Branch: `v0.4-dunes`.

**Stack**: Three.js (WebGL) + Web Audio API + vanilla JS modular. Capacitor wrap para Play Store en v1.0.
